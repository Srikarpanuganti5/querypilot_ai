# Synthetic sample data

This directory contains developer analytics queries and one-time reader-role provisioning
SQL. Synthetic rows are generated by `python -m querypilot.db.seed`, not committed as a
large dump. See docs/database.md for the explicit reference date, seed, accounting rules,
and actual row counts. Names/products are synthetic and emails use `example.invalid`.
Never add customer records, private documents, credentials, or production exports.
